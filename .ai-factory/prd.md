# SubTrack

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
OTT·앱 등 매달 자동결제되는 구독 서비스를 한곳에 모아 총 지출과 갱신일을 관리해주는 구독 트래커

## Problem
여러 구독 서비스 결제가 흩어져 있어 총 지출 파악이 어렵고, 불필요한 구독을 해지할 타이밍을 놓치는 경우가 많다. 토스 자체 가계부는 구독 특화 관리 기능이 약하다.

## Target Users
20~30대 다중 구독 서비스 이용자(OTT, 음악, 클라우드 등)

## Core Features
1. 구독 서비스 등록(템플릿+직접입력)
2. 월 총 구독비 대시보드
3. 갱신일 D-day 리마인더
4. 구독료 인상 감지 메모
5. 동일 연령대 평균 구독비 비교
6. 해지 체크리스트

## Monetization
- Model: freemium
- Estimated MRR: 월 약 14~15만원 (무료: 배너/리워드 광고, 유료: 무제한 항목 등록·알림 구독)
- Reasoning: 구독 갯수 3개 제한 후 무제한 등록은 프리미엄으로 유료화, 무료 유저는 비교 리포트를 리워드 광고로 게이팅. 갱신일 임박 시 재방문이 자연스럽게 발생.
